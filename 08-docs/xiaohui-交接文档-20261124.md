## 1. 项目是什么

一只 6 路舵机的 ESP32-S3 AI 机器狗「小慧」：能语音对话、查天气新闻、放音乐、做动作、控制灯珠、显示表情。
系统由 4 部分构成：设备固件、语音服务、控制台、大模型专区（云端 DeepSeek）。

## 3. 运行环境要点（踩过的坑）

1. **控制台必须用自身 venv 启动**：
   `D:\AI-Companion-shared\xiaohui-ai\console\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8080`
   （Anaconda 里没有 uvicorn）
2. **控制台环境变量缺一不可**（否则设备连不上/心跳 503）：
   `WS_URL`、`DEVICE_TOKEN`、`LLM_PROVIDER=openai`、`ZONE_URL`、`ZONE_MODE`、`VOICE_DIR`、`HARDWARE_TOKEN`、`KB_URL`、`MUSIC_BASE_URL`、`AUDIO_*`、`XIAOHUI_DEFAULT_CITY`
   → 已固化在启动脚本里；`console\data\ws_url.txt` 作为 `WS_URL` 文件兜底
3. **语音服务**启动需要：`USERPROFILE/HOME=.home`、`MODELSCOPE_CACHE=.mscache`、`HF_HOME=.hfhome`、`PATH=.venv\Scripts`、`CONSOLE_URL`、`KB_URL`、`ZONE_*`
4. **日志**：`voice-server\...\tmp\server.log`（loguru 每日轮转）。守护进程**不能**打开该文件，否则轮转失败导致语音启动崩溃（已修）。
5. **固件烧录**：`idf.py -p COM4 -b 460800 flash`；环境 `IDF_PATH=D:\esp\v6.1\esp-idf`、`IDF_TOOLS_PATH=C:\Espressif`，使用 `C:\Espressif\tools\python\v6.1\venv\Scripts\python.exe` + `idf_tools.py export`。
6. **设备 OTA**：固件从 `http://<你的服务器局域网IP>/ota/` 取配置（`CONFIG_OTA_URL`），下发 `websocket.url`。若控制台没配 `WS_URL`，会下发 127.0.0.1 导致设备连自己 → 永远离线（已修，现按请求 Host 生成）。

## 4. 架构与数据流

```
设备 (ESP32-S3, ws://<你的服务器局域网IP>:8000/xiaozhi/v1/)
  ↓ 音频帧 (Opus 24k)
语音服务 8000
  ├ 问候 → 固定短句（_speak_ack，不走模型）
  ├ 日期/天气/新闻 → 本地直查（Open-Meteo / 中新网 RSS，带 10 分钟缓存）
  ├ 知识库关键词 → 8077 /kb/search 直出
  ├ 工具类关键词（灯/动作/搜索/知识库）→ 本地模型 + MCP
  └ 其他对话 → 大模型专区 8013 → DeepSeek 云端（可 function calling）
控制台 8080
  ├ /chat 在线互动：文字对话、动作、灯珠、语音播报、动作编排
  ├ 设备 OTA / 心跳 / 硬件指令队列（心跳 400ms 取命令）
  └ 网页对话也走专区（ZONE_MODE=all），失败回退本地 r5
```

**设备动作执行**：语音/网页 → MCP 直连 `self.dog_action` / `self.set_led` / `self.led_effect` / `self.set_servo` / `self.set_pose`；自定义姿态走控制台心跳 `pose` 指令。

## 5. 当前配置快照

- 音色：`zh-CN-XiaoxiaoNeural`（晓晓），语速 `+25%`，静音判定 `350ms`（`voice_settings.json`）
- VAD：`threshold 0.25`、`min_silence_duration_ms 350`（`.config.yaml`）
- ASR：FunASR SenseVoiceSmall，`language="zh"`，噪声过滤已开
- 专区：`deepseek-flash`，`DOG_MAX_TOKENS=700`，普通回答 90 tokens / 故事 350 tokens（语音侧按关键词切换），简单闲聊跳过工具决策
- 人设：专区 `.env` 的 `DOG_SYSTEM_PROMPT` ≈「小慧，温柔有耐心，口语化，1~2 句，不说汪汪，不编造」
- 提示词/历史：语音侧只带最近 6 条历史

## 8. 已知问题与注意事项

- 设备供电偏弱：做动作时舵机瞬时电流会导致抽搐/重启，建议加 1000µF 电容或独立 5V 供电
- 语音服务重启后设备需要几十秒重连；控制台重启会让设备断开一次
- 语音回复延迟物理下限约 2 秒（DeepSeek 网络+生成）
- 控制台改音色/姿态后，语音侧有 60 秒缓存
- 会话中多次因「重启服务未带全环境变量」导致设备时好时坏，务必用启动脚本

## 11. 建议新会话先做的三件事

1. 跑一次健康检查 + 看设备连接数（`/api/console/status` 的 `count`）
2. 若设备离线：让用户断电重启；确认 `/ota/` 返回的 websocket 是 `ws://<你的服务器局域网IP>:8000/...`
3. 插 USB 烧固件（`self.set_pose`），然后验证动作编排：添加 3 步 → 试播 → 保存 → 列表播放
